# ARTEMIS I — Mission Website

A modern, immersive website dedicated to **Artemis I**, NASA’s first mission in the Artemis program.

The project presents the mission through a cinematic, editorial-style interface inspired by spacecraft systems, mission control dashboards, and scientific archives.

## 🚀 About the Project

Artemis I was an uncrewed test flight launched on November 16, 2022. During the mission, the Orion spacecraft traveled around the Moon and returned safely to Earth on December 11, 2022.

This website combines mission information, large-scale imagery, technical details, and a visual timeline to create an immersive storytelling experience.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Cinematic dark interface
- Technical grid and mission-control-inspired visuals
- Mission timeline
- Interactive sections and smooth animations
- Detailed information about the Artemis I mission
- Optimized layout and user experience
- Modern editorial typography

## 🎨 Design Concept

The visual direction combines:

- NASA mission documentation
- Modern editorial design
- Technical interfaces
- Minimal typography
- Dark space-inspired visuals

The goal was to create an experience that feels like exploring a digital mission archive rather than reading a traditional informational website.
